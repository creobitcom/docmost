# Обязательный первый блок

## Описание

Система обязательного первого блока обеспечивает, что на каждой странице всегда есть хотя бы один блок, который нельзя удалить. Это предотвращает ситуации, когда страница остается полностью пустой.

## Основные компоненты

### 1. `required-first-block.ts`
Основные утилиты для работы с обязательным первым блоком:

- `createRequiredFirstBlock()` - создает обязательный первый блок
- `isRequiredFirstBlock()` - проверяет, является ли блок обязательным
- `canDeleteBlock()` - проверяет, можно ли удалить блок
- `validateAndFixBlocks()` - валидирует и исправляет структуру блоков
- `createMigrationScript()` - создает миграцию для существующих страниц

### 2. `migrate-required-first-block.ts`
Скрипт для миграции существующих страниц:

- `migratePage()` - мигрирует одну страницу
- `migrateAllPages()` - мигрирует все страницы в пространстве
- `checkMigrationStatus()` - проверяет статус миграции

### 3. `required-first-block.css`
Стили для обязательного первого блока:

- Визуальные индикаторы (звездочка, цветная граница)
- Анимации появления и hover эффекты
- Поддержка темной темы
- Адаптивность для мобильных устройств

## Использование

### Автоматическое создание
Обязательный первый блок создается автоматически при:
- Создании новой страницы
- Загрузке страницы без блоков
- Миграции существующих страниц

### Проверка статуса
```typescript
import { checkMigrationStatus } from './migrate-required-first-block';

const status = await checkMigrationStatus('page-id');
console.log('Has required first block:', status.hasRequiredFirstBlock);
```

### Миграция страниц
```typescript
import { migrateAllPages } from './migrate-required-first-block';

// Мигрировать все страницы в пространстве
const stats = await migrateAllPages('space-id');
console.log('Migration completed:', stats);
```

### Использование в консоли браузера
```javascript
// Мигрировать конкретную страницу
window.migrateRequiredFirstBlock.migratePage('page-id');

// Мигрировать все страницы в пространстве
window.migrateRequiredFirstBlock.migrateAllPages('space-id');

// Проверить статус страницы
window.migrateRequiredFirstBlock.checkStatus('page-id');
```

## Особенности

### Идентификация обязательного блока
Обязательный первый блок идентифицируется по:
- Флагу `isRequired: true` в объекте блока
- ID, начинающемуся с `required-first-block-`

### Защита от удаления
Обязательный первый блок защищен от удаления на нескольких уровнях:
1. В `BlockEditor` - проверка при нажатии Backspace
2. В `useBlockManagement` - проверка в `deleteBlockSafely`
3. В `canDeleteBlock` - общая проверка возможности удаления

### Визуальные индикаторы
- Звездочка (★) слева от блока
- Синяя граница слева
- Градиентный фон
- Отключенный drag handle
- Скрытая кнопка удаления

## Конфигурация

### Создание блока с заголовком
```typescript
const requiredBlock = createRequiredFirstBlock(pageId, {
  blockType: 'heading',
  title: 'Заголовок страницы',
  placeholder: 'Введите заголовок...'
});
```

### Настройка плейсхолдера
```typescript
const requiredBlock = createRequiredFirstBlock(pageId, {
  placeholder: 'Начните писать...'
});
```

## Миграция

### Автоматическая миграция
При загрузке страницы система автоматически:
1. Проверяет наличие обязательного первого блока
2. Если блока нет - создает его
3. Перемещает существующие блоки в правильные позиции
4. Сохраняет изменения на сервере

### Ручная миграция
Для миграции существующих страниц используйте скрипт миграции:

```bash
# В консоли браузера
window.migrateRequiredFirstBlock.migrateAllPages('space-id');
```

## Отладка

### Логи
Система выводит подробные логи:
- Создание обязательного блока
- Проверки возможности удаления
- Процесс миграции
- Ошибки валидации

### Глобальные функции
```javascript
// Проверить статус миграции
window.migrateRequiredFirstBlock.checkStatus('page-id');

// Получить статистику миграции
const stats = await window.migrateRequiredFirstBlock.migrateAllPages('space-id');
console.log('Migration stats:', stats);
```
