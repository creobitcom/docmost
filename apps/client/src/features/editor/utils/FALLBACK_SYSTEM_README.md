# Восстановленная Fallback Система для Drag & Drop

## Обзор

Восстановленная fallback система обеспечивает надежное получение drag данных даже при сбоях отдельных компонентов. Система автоматически переключается между различными источниками данных в правильной последовательности.

## Архитектура

### Источники данных (в порядке приоритета)

1. **DragStateManager** - Первичный источник
   - Хранит состояние drag операции в памяти
   - Быстрый доступ к данным
   - Может быть очищен при сбоях

2. **DataTransfer** - Наиболее надежный fallback
   - Данные передаются через браузерный API
   - Сохраняются в формате JSON
   - Доступны во время drag операций

3. **DndCoordinator** - Координатор DnD операций
   - Поддерживает как элементы, так и блоки
   - Централизованное управление состоянием
   - Автоматическое восстановление

4. **Window Global State** - Последний резерв
   - Глобальное состояние в window объекте
   - Используется при полном сбое других источников

### 2. Автоматическое восстановление состояния

При успешном fallback восстановлении:
- Данные автоматически сохраняются в DragStateManager
- Состояние синхронизируется между источниками
- Ведется статистика восстановлений

## Использование

### Основные функции

```typescript

// Полная очистка состояния

```

## Статистика восстановлений

DragStateManager отслеживает:
- Количество fallback восстановлений
- Время последнего восстановления
- Необходимость принудительной очистки

```typescript
const stats = DragStateManager.getRecoveryStats();
// { count: 2, lastTime: 1234567890, isRecent: true }
```

## Обработка ошибок

### Автоматическое восстановление
- При сбое DragStateManager → DataTransfer
- При сбое DataTransfer → DndCoordinator  
- При сбое DndCoordinator → Window Global

### Принудительная очистка
- При частых fallback восстановлениях (>3 за 5 сек)
- При обнаружении невалидных данных
- При критических ошибках

## Устранение неполадок

### Проблема: Частые fallback восстановления
**Решение:** Проверить стабильность DragStateManager, возможно требуется очистка состояния

### Проблема: DataTransfer недоступен
**Решение:** Проверить поддержку браузера, использовать DndCoordinator fallback

### Проблема: Все источники недоступны
**Решение:** Проверить инициализацию системы, перезапустить drag операцию
