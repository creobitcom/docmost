# Инструкции по тестированию дроп-зон

## Как протестировать новый функционал

### 1. Откройте страницу в браузере
- Перейдите на любую страницу с блоками
- Откройте консоль разработчика (F12)

### 2. Проверьте наличие дроп-зон
В консоли выполните:
```javascript
// Проверить количество дроп-зон
testBlockDropZones()

// Сделать дроп-зоны видимыми
showDropZones()

// Проверить позиционирование дроп-зон
testDropZonePositioning()

// Проверить стили маркеров списков
testListMarkers()

// Симулировать драг элемента в дроп-зону
simulateElementDrag('element-id', 0)
```

### 3. Проверьте логи
В консоли должны появиться логи:
- `🎯 [BlockDropZone] Component mounted:` - создание дроп-зон
- `🎯 [PageEditor] Rendering drop zone before/after block:` - рендеринг дроп-зон
- `🎯 [PageEditor] 🔍 RENDERING BLOCK:` - рендеринг блоков

### 4. Тестирование drag & drop
1. Найдите элемент списка (bullet point или номер)
2. Попробуйте перетащить его в дроп-зону между блоками
3. Должен создаться новый блок с перемещенным элементом

### 5. Если дроп-зоны не видны
1. Выполните `showDropZones()` в консоли
2. Дроп-зоны должны стать видимыми с синей рамкой
3. Если их все еще нет, проверьте логи в консоли

### 6. Отладка
Если что-то не работает:
1. Проверьте логи в консоли
2. Убедитесь, что блоки имеют `hasAccess: true`
3. Проверьте, что элементы имеют `data-element-drag-handle="true"`

## Ожидаемое поведение

1. **Дроп-зоны видны**: Между блоками должны быть невидимые зоны высотой 20px
2. **Hover эффект**: При наведении курсора зона подсвечивается
3. **Drag over**: При перетаскивании элемента зона активируется
4. **Создание блока**: При дропе создается новый блок
5. **Автоматический драг**: Элемент перемещается в новый блок

## Возможные проблемы

1. **Дроп-зоны не отображаются**: Проверьте CSS и логи рендеринга
2. **Drag не работает**: Проверьте обработчики событий
3. **Блок не создается**: Проверьте функцию `handleCreateBlockFromElement`
4. **Элемент не перемещается**: Проверьте автоматический драг
