# Правила проекта DocMost

## Пакетный менеджер
- Используется **pnpm** для управления зависимостями
- Все команды установки: `pnpm install`
- Все команды добавления пакетов: `pnpm add <package>`

## Сборка и запуск
- **Сборка приложения**: `pnpm build`
- **Запуск сервера**: `pnpm start`
- **Разработка**: `pnpm run dev`

## Git workflow
- Используйте осмысленные сообщения коммитов
- Создавайте feature ветки для новых функций
- Тестируйте изменения перед мержем

## Стиль кода
- TypeScript для всех новых файлов
- ESLint и Prettier для форматирования
- Следуйте существующим паттернам в проекте

## База данных
- Используйте Kysely для запросов
- Создавайте миграции для изменений схемы
- Тестируйте миграции на тестовых данных

## API
- RESTful endpoints
- JWT аутентификация
- Валидация входных данных
- Обработка ошибок

## Frontend
- React с TypeScript
- Mantine UI компоненты
- Jotai для управления состоянием
- Tiptap для редактора

## Архитектура блоков
- Каждый блок имеет свой YDoc
- Отдельные HocuspocusProvider для каждого блока
- Права доступа на уровне блоков
- Миграция со старой архитектуры через API
