# Инструкции по тестированию системы блоков

## 🚀 Запуск системы

### 1. Запуск сервера
```bash
cd apps/server
npm run start:dev
```

### 2. Запуск клиента
```bash
cd apps/client
npm run dev
```

## 🧪 Тестирование функциональности

### 1. Тестирование перетаскивания элементов

1. Откройте страницу с редактором
2. Создайте список задач (task list) с несколькими элементами
3. Попробуйте перетащить элементы внутри списка
4. Проверьте, что элементы перемещаются в правильные позиции

**Ожидаемое поведение:**
- Элементы должны иметь уникальные `data-element-id`
- Перетаскивание должно работать плавно
- Элементы должны вставляться в правильные позиции

### 2. Тестирование автоматического сохранения

1. Отредактируйте содержимое блока
2. Подождите 1-3 секунды
3. Перезагрузите страницу
4. Проверьте, что изменения сохранились

**Ожидаемое поведение:**
- Изменения должны сохраняться автоматически
- После перезагрузки содержимое должно остаться

### 3. Тестирование API блоков

1. Откройте консоль браузера (F12)
2. Загрузите тестовый скрипт:
```javascript
// Скопируйте и вставьте содержимое test-blocks-api.js
```

3. Запустите тест:
```javascript
window.testBlocksAPI.runTest()
```

**Ожидаемое поведение:**
- API должен успешно создавать, обновлять и получать блоки
- В консоли должны появляться сообщения об успешных операциях

## 🔍 Отладка

### Логи в консоли браузера

Ищите следующие сообщения:
- `🔄 [startPeriodicSave]` - периодическое сохранение
- `💾 [saveBlocksToServer]` - сохранение на сервер
- `📝 [EnhancedTaskItemView]` - генерация ID элементов
- `🔄 [UnifiedDragHandlers]` - обработка перетаскивания

### Логи на сервере

Ищите следующие сообщения:
- `🔄 [PageController] updateBlocksForPage` - получение запроса на сохранение
- `🔄 [PageService] saveBlocksForPage` - обработка сохранения
- `✅ [PageService] saveBlocksForPage completed` - успешное сохранение

### Проверка уникальности ID элементов

В консоли браузера выполните:
```javascript
// Проверить все data-element-id на странице
Array.from(document.querySelectorAll('[data-element-id]')).map(el => el.getAttribute('data-element-id'))
```

Все ID должны быть уникальными.

## 🐛 Известные проблемы

### 1. Элементы с одинаковыми ID
**Проблема:** Все элементы списка имеют одинаковый `data-element-id`
**Решение:** Проверить логику генерации ID в `EnhancedTaskItemView`

### 2. Перетаскивание не работает
**Проблема:** Элементы не перемещаются при перетаскивании
**Решение:** Убедиться, что у каждого элемента уникальный ID

### 3. Изменения не сохраняются
**Проблема:** После перезагрузки изменения теряются
**Решение:** Проверить логи периодического сохранения

## 📊 Мониторинг производительности

### Проверка частоты сохранения
```javascript
// Подсчитать количество сохранений за последние 5 минут
let saveCount = 0;
const originalLog = console.log;
console.log = function(...args) {
  if (args[0]?.includes('[saveBlocksToServer] Success')) {
    saveCount++;
  }
  originalLog.apply(console, args);
};
```

### Проверка размера данных
```javascript
// Проверить размер сохраняемых данных
window.debugBlocks = function() {
  const blocks = document.querySelectorAll('[data-block-id]');
  console.log('Total blocks:', blocks.length);
  blocks.forEach((block, index) => {
    const content = block.textContent;
    console.log(`Block ${index}: ${content.length} characters`);
  });
};
```

## 🎯 Критерии успеха

✅ **Система работает корректно, если:**
1. Все элементы списка имеют уникальные ID
2. Перетаскивание элементов работает плавно
3. Изменения автоматически сохраняются
4. После перезагрузки данные не теряются
5. API блоков работает без ошибок
6. В логах нет критических ошибок
